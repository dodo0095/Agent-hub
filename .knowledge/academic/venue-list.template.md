# 目標投稿 Venue 清單（範本）

> **這是 Hub 內的通用範本，不含任何個人投稿紀錄或個人目標排序。**
>
> 使用方式：
> 1. 複製本檔到**你的專案工作目錄**：`<專案根目錄>/.knowledge/academic/venue-list.md`
> 2. 依研究者的領域填入目標期刊 / 研討會與優先順序（對照 `scholar-profile.md` 的研究主軸與投稿紀錄）
> 3. 該路徑已列入 Hub 的 `.gitignore`；個人版本只放在你的專案資料夾，**不要**放回 Hub repo
>
> 期刊 IF、截稿時間、等級會變動，填寫時請附查核日期與來源，不要憑印象填。

## 5. 選擇 Venue 的決策邏輯（填入你的主軸與 venue）

```

      ↓
主軸 A ({{名稱}})?
  期刊 → {{venue 排序}}
  研討會 → {{venue 排序}}

主軸 B ({{名稱}})?
  期刊 → {{venue 排序}}
  研討會 → {{venue 排序}}
      ↓
判斷時程壓力
      ↓
趕發表 → {{快速審查 venue}}
有充裕時間 → {{高影響力 venue}}
研討會先試水 → {{熟悉的研討會}} → 修改後投期刊
```
