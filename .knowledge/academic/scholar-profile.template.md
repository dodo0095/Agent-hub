## 7. Agent 使用本檔案的時機

| Agent | 何時讀本檔案 |
|-------|-------------|
| `research-director` | 每次接收新任務時，先讀本檔確認研究主軸 |
| `literature-scout` | 搜尋前對照第 2 節選定關鍵字；引用前對照第 5 節自引規則 |
| `paper-writer` | 撰寫 Introduction 時參考主軸定位；引用時照第 5 節 |
| `grant-writer` | 國科會計畫書第一步必讀，確認計畫方向與研究脈絡 |
| `manuscript-reviewer` | 審外部稿件時**不讀**（避免偏見）；內審自家草稿時可參考 |
| `research-visualizer` | 圖表風格可延續研究者既有成果的視覺語言 |
| `research-analyst` | 方法學選擇對照第 4 節技能樹 |
